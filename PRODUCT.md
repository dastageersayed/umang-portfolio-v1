# Product

## Platform

web

## Stack
Vite + React + TypeScript + Tailwind CSS. Single-page static site, no router, no backend. Deploy target: Vercel or Netlify (static).

## Users
Recruiters and hiring managers screening QA Engineer candidates, usually scanning for under a minute, then engineering leads who read deeper. Owner and subject: Umang Sharma, ISTQB-certified QA Engineer, 5+ years, Chandigarh, India.

## Product Purpose
Personal portfolio whose single job is to land QA Engineer roles. Success: a recruiter understands within seconds that Umang is a rigorous, certified QA engineer, sees proof of how he tests, and contacts him or downloads the CV.

## Positioning
A QA portfolio built around a 3D bug as the hero artifact: the person who finds the bug, presented with the bug itself. A developer portfolio template cannot copy that framing.

## Operating Context
Viewed on laptops and phones, often from a recruiter's inbox or LinkedIn link. Work history spans manual and Selenium automation testing, API testing (Postman, Swagger), SQL validation, JMeter, release validation, AI-enabled app testing. Client work is mostly under NDA, so projects appear as anonymized case studies.

## Capabilities and Constraints
- Sections in order: Hero, Work, Approach, Experience, About, Contact. Slim top nav with anchors.
- Hero: Sketchfab "Bug" model by vitalysh (https://sketchfab.com/3d-models/bug-199e4a1ec2be46a48351e6a95ead7085), embedded. Turns toward the cursor on desktop via the Sketchfab Viewer API; drag still works; touch is drag only; reduced motion disables tracking. Author credit stays visible in the footer. Model license not yet confirmed (open decision, user to check on Sketchfab).
- Project cards use screenshots (placeholders until supplied). No video. No audio of any kind.
- Contact shows email, phone, LinkedIn, CV download.
- Skills shown as grouped lists, never percentage bars or star ratings.

## Brand Commitments
Plain first-person copy, sparing bug-report field labels as section headings only. No buzzwords. No photo of the owner. The reference site (ahmed-m-portfolio.vercel.app) is used for section order only, never its look, motion or copy.

## Product Principles
1. Proof of rigor before personality.
2. The bug is the artifact; the interface recedes around it.
3. No invented numbers; placeholders are labeled.
4. Fast for a one-minute skim, deep for the curious.

## Accessibility & Inclusion
Keyboard navigable, visible focus, WCAG AA contrast, prefers-reduced-motion respected, 3D hero has a text equivalent and does not trap scroll on touch.
